# 手机库独立全商品展示：本地交付

用户要求把手机库与智能选机分开，手机库用于全商品展示。已在 `codex/independent-product-catalog-20261028` 本地实现，基于 `d85dc23`；未推送、合并或发布公网。

## 当前行为

- 手机库默认查询全部成色，预算、存储、品牌和搜索不限，显示 **147个机型、484个配置**。每页24配置，共21页，末页4配置；保留现有主展示卡、其他配置、详情、评价和对比入口。
- 手机库有自己的成色、最低/最高价格、最低存储、包含/排除品牌控件。已应用条件常显，结果同时标明机型数和配置数。
- 智能选机的预算/品牌/成色/偏好不再用于手机库；修改选机条件也不会清空手机库结果、筛选或拒绝其正常未完成请求。
- 手机库搜索、分类、筛选、分页、恢复全部商品，不修改智能选机表单，不撤销其已确认推荐与导出。
- “恢复全部商品”同时恢复全部成色、清空手机库条件/搜索、回到全部场景与第1页。
- 未提交的筛选控件不会通过翻页、搜索或分类操作偷偷生效；只有点击“应用手机库筛选”才应用表单条件。切换页面保留手机库已应用条件和页码。
- 数据/运行版本变化仍统一撤销旧结果，并重新载入目录，避免跨版本内容混用。

实现为独立 `catalogState` 与已应用 `catalogFilters`；`frontend/catalog.mjs` 提供默认条件、查询编码、条件摘要及正确机型数口径。保留原有目录接口和数据；未改AISM、需求抽取、七维权重或排序算法。
