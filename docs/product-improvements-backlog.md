# 知选产品优化待办

## UX-001：「为什么推荐」改为面向选机用户的自然语言

- 记录日期：2026-10-23。
- 状态：已实现、合并PR #1，并于2026-10-24发布至https://zhixuanji.cn/，完成公网接口及桌面浏览器验收。原要求先记录；用户随后明确授权实施、上传、合并与更新网页。
- 适用位置：正式 HTML 网页的手机推荐卡片中「为什么推荐·证据与限制」区域。

### 当前问题

面向普通选机用户的解释区域直接展示算法名、版本、权重结构、哈希和原始 JSON。
这些内容便于开发核查，但不能直接回答“这部手机为什么适合我”。

### 后续改进要求

1. 首先用简短、自然的中文解释推荐理由：用户关心什么、这部手机如何匹配、有哪些取舍。
2. 理由必须对应用户已确认的需求与真实商品数据；不要只重复参数或只说“综合评分较高”。
3. 主动说明影响选择的短板和数据缺失；不以像素、芯片名称等参数擅自推断拍照或游戏表现。
4. TOPSIS 分数、算法/数据版本、权重、来源 ID、哈希及原始结构移到默认收起的「查看数据与计算依据」中，保留可追溯性。
5. 可采用确定性自然语言模板，或在现有证据约束下由 LLM 润色；本待办不授权新增付费调用或改变排序。

### 验收方向

- 用户无需理解算法或 JSON，就能看懂主要推荐理由及至少一个有依据的取舍/限制。
- 每条解释可追溯到当前用户确认条件及同一次推荐的证据，不能编造功能、实时价格或使用体验。
- 不把相对排序分、后验支持率解释为购买概率或满意度。
- 技术信息仍能展开核查，但不再成为普通用户看到的第一层解释。

## UX-002：手机库增加游戏、长辈友好、拍照场景分类

- 记录日期：2026-10-23。
- 状态：分类入口、资料状态筛选与来源展示已实现、合并PR #1，并于2026-10-24发布至https://zhixuanji.cn/，完成公网验收。完整适用性标准仍待数据验证，不将“有评测资料”当成性能优秀或适合所有用户。
- 适用位置：手机库的分类入口、筛选与机型标签。
- 目标：帮助不熟悉参数的用户按用途浏览，而不是把厂商宣传中的产品定位直接当作推荐结论。

### 展示与分类方式（拟议）

- 手机库增加「全部 / 游戏手机 / 长辈友好 / 拍照手机」入口，长辈友好对应用户提出的“老年手机”。
- 采用可重叠的场景标签，不强制三选一；普通旗舰也可能适合游戏，同一机型可以同时适合游戏和拍照。
- 区分厂商定位、功能是否具备、场景适用性三件事；没有证据的机型标为「待评估」，不等同于不具备或不推荐。
- 分类不能绕过预算、存储、品牌排除等用户已确认的硬约束；本待办不授权修改现有推荐权重或排序。

### 初步评估维度

| 分类 | 优先核查的维度 | 不可采用的简单判断 |
| --- | --- | --- |
| 游戏手机 / 游戏优先 | 目标游戏的持续帧率、帧时间或低帧表现、长时间掉帧、机身温度、游戏耗电、触控延迟与适配；补能和握持作为补充 | 不能仅凭芯片名、综合跑分、屏幕刷新率、散热面积或“电竞”宣传贴标签 |
| 长辈友好 | 大字体与图标、简易模式、通话与扬声器、系统广告及应用安装管理、续航、紧急联系人、无障碍与家人协助；考虑用户熟悉的系统和握持负担 | 不能把低价、大电池或年龄直接等同于适用；不宣称某品牌所有机型都无广告、好用或防诈骗 |
| 拍照手机 / 拍照优先 | 实拍样张与可信测试中的日常、夜景、人像、运动抓拍、长焦表现；防抖、对焦、镜头与传感器规格作为辅助；注明优势场景和不足 | 不能把高像素、镜头数量、联名或支持 OIS 直接当作画质优秀；拍照与视频能力不能混为一谈 |

以上是待验证的评价维度，不是已经确定的入选门槛。暂不规定统一的帧率、温度、电池容量、像素或价格阈值，也不虚构场景分数。

### 网上讨论如何转为可执行标准

1. 帖子用于提取用户关注点，不直接充当手机性能真值。后续按三类场景检索多平台近期原帖，记录发布日期、采集日期、互动量快照和场景，去重并标注广告、合作测评、转载与 AIGC。
2. 当前是少量社区讨论及评测的定性参考，未完成热门帖排名、批量采集或频次统计，不应对外称“基于全网热门帖子数据自动分类”。旧文只能辅助定义维度，不能当作当前选购榜单。
3. 商品标签落地时，功能证据以对应中国市场型号的官方说明和功能核查为基础，体验结论需可追溯实测或样张。记录型号/版本、系统版本、来源链接、测试或核查日期、适用场景、审核人及规则版本。
4. 游戏数据需保留游戏及版本、画质/分辨率、帧率档、运行时长、环境温度、性能模式等条件；原生渲染帧与插帧分开记录，不能混比。影像测试也应保留场景与测试协议，不直接拼接不同协议版本的总分。
5. 实现前再依据可获得证据确定门槛与缺失值策略；先抽样人工双人复核，再批量标注。对广告多少、简易模式可用性等随系统变化的项目应定期复查。

### 本轮参考来源与限制

- [V2EX：求推荐 2000 元以内、适合父母用的安卓手机](https://v2ex.com/t/1185495)：讨论涉及少广告、字体音量、续航和日常稳定性，仅提取需求，不采用评论中的型号价格与品牌结论。
- [V2EX：求助帖父亲手机选择](https://v2ex.com/t/1192138)：反映操作、系统习惯和续航等个人差异，不把个别人的体验泛化到所有长辈。
- [安兔兔：红魔游戏手机 12 Pro+ 体验](https://www.antutu.com/doc/137994)（2026-10-15）：参考其持续帧率、低帧、功耗、温度和游戏适配的观察维度，不采用文中单机成绩作为全体机型的统一门槛，也未复现实测。
- [少数派：小米 14 Pro 上手体验](https://sspai.com/post/84510)（2023-12-15）：参考实拍、色彩与多焦段的评价角度；文章披露众测合作背景，且不是当前机型榜单，不作独立、全面的影像能力证明。
- 检索时遇到的 AIGC 汇编、无法核验的转述和正文不可访问的视频，不用作具体机型的分类证据；本轮未分配任何实际机型标签。

### 后续验收方向

- 手机库能按场景筛选，并继续尊重用户的预算等硬约束。
- 每个标签展示简短自然语言依据与来源；不暗示各场景都优秀，也不以热度代替质量。
- 覆盖同机多标签、证据不足、没有符合条件机型、版本变化导致标签失效等情况。
- 缺失数据明确显示「待评估」；不得用编造的游戏、拍照、适老体验填充现有手机库。
