# 七维规格参考分（2026-10-27）

## 实施规则

用户授权使用简单规格代理评价各维度，采用百分制。新增 `spec_reference` 模式；旧请求省略模式仍走 `measured`，网页默认采用规格参考。价格和品牌仅用于筛选。偏好初值为存储 3、重量/电池/芯片 2、屏幕/拍照/游戏 1；明确“不在意”仍为 0。

所有函数固定锚点、裁剪到 0—100，不随候选集改变；综合排序分仍是当前候选集的相对排序分，与这些分项不同。

|维度|v1 公式|含义与边界|
|---|---|---|
|存储|20 × log2(GB / 64)|64GB=0、256GB=40、1TB=80；容量参考，不含读写速度|
|重量|100 × (260-g) / 120|140g=100、260g=0；轻便参考，不代表握持感|
|电池|100 × (mAh-3000) / 5000|3000mAh=0、8000mAh=100；容量代理，不是实测续航|
|处理器|现有版本化芯片档位表|含第三方换算与估算；缺失型号不猜分|
|屏幕|100 × (1-abs(英寸-目标)/1.5)|尺寸匹配度，不是面板画质；目标改变会改变分数|
|拍照|40 × clip(log2(主摄MP/8)/log2(200/8)) + 超广角30 + 长焦30|影像规格参考；只统计已记录主摄像素与镜头种类，不代表成片质量|
|游戏|处理器参考分 × 80% + 电池容量参考分 × 20%|规格代理，不是帧率、功耗或实测游戏续航|

这些锚点和系数是本项目可审查的初始设计，未用真实用户实验校准。芯片、容量也在游戏代理中出现，用户同时提高其单项权重会重复强化相关偏好；不能将七维视为统计独立特征。

缺失或冲突保持空值，不能当成 0 分；正权重维度缺失的配置进入资料不足的备选。0 分表示按已记录规格计算得到的有效结果。保留原始输入、来源、规则版本、芯片表摘要和决策指纹，导出绑定同一决策。实测模式继续采用协议、范围和条件可比性检查，不混入规格代理。

## 来源核验与验收

芯片新参考资产为 `data/chipset-primary-reference.json`，旧表保留给原模式。依据[极客湾 SOCPK 官方历史图表](https://socpk.com/chart/chip-overall)核验：CPU 70% / GPU 30%，以骁龙865=100；综合指数除4并四舍五入、裁剪为项目参考分。榜单不包括功耗、AI、ISP和基带，抓取日期不是测试发布日期，不能称为最新整机游戏天梯。

53 个条目中，28 个核验到第一方同款、20 个沿用估算、5 个具体变体尚未匹配第一方资料；后两类保持明确标记。麒麟9030仍无匹配值，不推测9030 Pro等于9030。纠正三项：天玑8300-Ultra 42→44、6080 15→12、6020 14→11。原始综合指数、逐项来源和未匹配原因均在该资产中。参考规则版本额外绑定资产内容摘要，数据表变化会使旧确认及旧导出失效。
