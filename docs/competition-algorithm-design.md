# 知选：交互式多决策融合实验设计

状态：根据 2026-10-20 用户确认的竞赛方案实现；实验入口，不替换线上默认算法。

## 目标和基础

基于 v2 的 `codex/html-api-ui` 提交 21db545，复用规范目录、硬约束过滤、
DecisionInput 和数据发布校验。原 `engine.rank_decision_input` 和原推荐页面保持兼容。
本机其他目录中尚未提交的 DeepSeek/玻璃界面改动不复制、不覆盖。

实现 TOPSIS/TODIM 双路排序、RRF 融合、贝叶斯权重学习、信息增益与分歧驱动选题、
后验排名稳定性；VIKOR 的 Q 指数仅作为额外比较基线。
不实现/宣称深度学习训练、心理参数测量、真实用户效果提升或原创基础算法。

## 计算契约

- 候选由原 DecisionInput 判定可比性；不补零、不放宽预算、不跨评测口径混排。
- 每轮会话冻结候选、有效指标、目标屏幕和归一化。数据/条件改变必须重建会话。
- 只采样原权重大于零的指标；屏幕必须先确认目标。关闭指标不会被学习重新开启。
- TOPSIS 与原引擎逐 SKU 一致。TODIM 对收益方向的 min-max 指标计算经典成对占优：
  正差贡献 sqrt(w_j * delta)，负差贡献 -sqrt(-delta / w_j) / theta。
  theta=1 为实验默认；对照 theta=0.5/1/2，不能将其称为测得的个人损失厌恶。
- TODIM 对全部冻结候选求和，不能只对被询问的两台手机重新归一化。
- 同分使用平均名次；RRF = alpha/(k+r_T) + (1-alpha)/(k+r_D)，默认 alpha=.5、k=10。
  主融合输出是后验下 RRF 分数的期望，不是对两个异尺度分数求平均。
- VIKOR 输出 Q（越小越好）及 1-Q 用于排序对照，不宣称满足完整折中解接受条件。

## 偏好学习与提问

256 个 Dirichlet 权重粒子，alpha_j=1+12*w0_j，先验概率均匀，固定随机种子 20261020。
用于回答似然的模型是 min-max 收益指标的加性效用；不是 TOPSIS 分数生成的标签。
P(A|w)=.05+.9*sigmoid((u(A,w)-u(B,w))/.12)，贝叶斯更新粒子概率。
这些噪声/先验参数是模型假设，要报告敏感性，不代表真实心理测量。
跳过/无明显倾向均不更新权重；记录问题并不再重复。最多 5 题，可撤销并从先验重放。

在三个当前排名各前 8 名的并集中产生问题，限制不同独立机型；
过滤相同指标向量和 Pareto 支配关系。以同一问题池比较 random / information /
disagreement 三种选题策略。
信息增益 IG=H(E[p])-E[H(p)]；分歧 D 是后验下两算法对该对候选严格反序的概率。
综合选题值 IG*(1+0.5*D)，保证纯分歧且无信息的问题不会被单独奖励。
若无有意义问题或达到题数限制则结束，不将有限粒子的集中直接当作真实准确率。

报告每个 SKU 的原 TOPSIS、后验平均 TOPSIS/TODIM/RRF、VIKOR 对照、
前一名支持率（并列均分）、名次均值/标准差和权重均值。
“支持率”仅指当前模型/先验下的统计量，不是满意概率。
包含算法配置、会话指纹、数据指纹、回答记录和版本，可复算。

## 2026-10-22 复核后的修订

- 默认展示学习后 TOPSIS、默认选题采用纯信息增益。TODIM、RRF、VIKOR 与加性效用
  都可单独查看；切换展示算法不会改变回答或已学习的后验。
- 经典 TODIM 保留公式定义，但不再将其视为自动优于 TOPSIS 的替代：负差项含
  逆权重，两个完全交叉的指标可能产生权重反序。例：A=(1000元,200克)、
  B=(2000元,100克)，权重=(.8,.2) 时 TOPSIS 选 A、TODIM 选 B，等比例 RRF 同分。
  此例已加入回归测试。若日后修改损失权重，必须另命名变体并重新验证。
- 每条算法分别计算后验第一名支持率、平均名次和标准差；权重导出 5%/95% 分位。
  有效粒子数低于总数 10% 时提示后验集中，不据此声称高置信度或自动停止。
- 实验增加各算法的无回答先验和同一回答轨迹下的学习后结果；总计 25 个方法，
  可区分先验平滑、偏好学习和融合的贡献。加性效用是学习模型自身的诊断基线。
- 总体成对准确率之外，另报排除 Pareto 支配对的取舍对准确率。
  以同一模拟用户的差值做 2000 次配对 bootstrap，报告探索性 95% 区间；
  不作多重比较校正，不将区间解释为真实消费者效果。
- 旧种子 20261020 的 24 人/效用族用于探索；固定默认参数后增加种子 20261021
  与 20261022，各 96 人/效用族的重复模拟，保留全部结果，不挑最优参数报喜。
  重复模拟仍共享同一个手机目录，只检验随机模拟稳健性，不能证明跨目录泛化。

## 验证与实验

单元测试覆盖经典 TODIM 手算、RRF 同分、原 TOPSIS 等价、零权重、缺失/单机型拒绝、
后验方向、跳过/撤销、选题重复/支配/机型限制、数据/配置指纹和稳定性并列处理。
界面测试用真实发布库，确认开启、回答、撤销、改条件使旧会话失效。

离线实验：固定候选与种子，逐用户使用同样潜在偏好和相同题数预算；
同时报告纯 TOPSIS/TODIM/VIKOR/固定融合、随机/信息/分歧追问。
合成用户包括线性和非线性短板敏感效用；后者用于观察模型失配。
只保留未询问的候选对作为最终偏好预测测试，报告成对准确率、Top-1 效用后悔、
按潜在效用得到的 NDCG@5、真实已问题数；保留负结果与逐用户原始记录。
不能用 TOPSIS 的排名充当正确答案；不据此声称真实消费者效果。
