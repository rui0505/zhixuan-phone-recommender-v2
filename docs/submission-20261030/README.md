## 如何核对算法

按仓库首页安装依赖后，在项目根目录执行：

```powershell
.\.venv\Scripts\python.exe docs/submission-20261030/evidence/复算示例.py
```

构造方案A、C的融合分均约为0.083916，B约为0.083333，D约为0.071429。脚本调用项目实际排序模块；A与C并列，稳定展示顺序不代表其中一个更优。固定功能版本不含后续新增的材料目录；如切换到固定提交复算，请先把证据脚本另存到仓库外，再从项目根目录运行该脚本的绝对路径。

## 用户反馈的收集与统计

团队通过线下组织用户试用网页，配合手机知识讲解，提供了100条评价记录。整理时比对了原始导入记录与2026-10-29保存的公开接口结果，记录数量、正文集合和评分分布一致。仅在此发布汇总统计和已公开页面截图，不附原始昵称清单、完整生产数据库或管理凭据。

原表日期范围为2026-07-31至2026-10-27，2026-10-29统一导入发布；这两个时间概念分别记录。原表未逐条绑定代码版本，因此不把全部反馈解释为针对当前混合算法版本的独立验证。均分计算为 `(65×5+35×4)/100=4.65`。综合体验34条、推荐功能30条、UI界面21条、页面流畅度15条。

这些反馈支持本批次有讲解条件下的主观体验总体积极，不能换算为算法准确率，也不能证明混合算法优于某个基线。截图中的评论为用户原话，功能是否实现以代码及验证记录为准。
