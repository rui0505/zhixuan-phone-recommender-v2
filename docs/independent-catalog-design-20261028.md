# 手机库独立全商品展示

用户要求手机库与智能选机分隔，作为全商品展示。当前目录接口已能返回147机型/484配置；问题在前端直接读取选机表单，并在清空目录时重置选机条件。

采用独立手机库筛选、请求状态与已应用筛选快照。默认全部成色、预算/品牌/存储不限、全部场景、搜索为空。保持现有24配置分页、真实配置与来源；不将配置数冒充机型数，不一次渲染全部484配置。

手机库提供自己的预算、成色、最低存储与包含/排除品牌控件。搜索、场景和分页只使用手机库状态。清空恢复全库默认，不改选机表单、偏好、已确认推荐或导出。智能选机变化也不清空手机库筛选、结果或正在完成的目录请求。数据版本变化仍同时使旧结果失效，防止跨版本混用。

目录状态单独保存，复用现有接口及状态令牌机制；不新增后端算法或数据。保留既有DOM入口ID，将原“修改筛选”改为定位手机库本地控件。已应用条件摘要常显，目录状态同时写机型数与配置数。未提交的筛选表单不会通过翻页偷偷生效，切换页面保留手机库条件。

验证先写真实app处理器回归：默认全库、两向隔离、清空不撤销推荐、翻页/搜索和乱序响应。再检查真实HTTP总数、浏览器推荐3000元后手机库仍147机型/484配置、自己的筛选可用，以及桌面/390px布局。仅本地实现，保留AISM及现有评分，暂不推送或发布。
