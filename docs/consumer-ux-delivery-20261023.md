## 本次交付

### UX-001：面向选机用户的解释

- 推荐卡片首先显示“为什么适合你”、最多三个匹配点、取舍与数据限制。
- 理由依据同一次已确认需求、有效权重、实际数据及证据；不把未加权的指标说成用户重点。
- 屏幕以与用户目标尺寸的偏差解释，不宣称越大越好；游戏与影像不能从芯片、像素、刷新率推断体验。
- 原 TOPSIS 分数、版本、指纹、权重、事实 ID 和原始说明保留在默认收起的“查看数据与计算依据”。
- 无新增大模型调用、无新增 API 费用；原有可选辅助核查仍在技术展开区，由用户单独触发。
- 相对价格比较只在明确同日、同成色、同估价标记的候选间进行；模糊日期不转成精确日期，也不参与同日价格比较。

### UX-002：手机库场景分类

- 新增全部、游戏手机、长辈友好、拍照手机入口，并支持“有评测资料 / 待评估机型”状态。
- 采用可重叠标签。当前版本是资料参考池，不是性能或适用性认证；分类依据及社区参考链接可展开查看。
- 分类在分页前执行，并与预算、品牌、最低存储、搜索、成色共同生效；计数按机型去重，卡片按准确配置展示。
- 当前完整目录：147 机型 / 484 配置。游戏有资料65款、待评估82款；影像有资料55款、待评估92款；长辈147款均待评估。
- 游戏需要有来源的正数平均帧率，影像需要有来源的照片子项；不以相机总分、硬件参数或品牌印象替代证据。
- 当前没有经过核实的大字体、简易模式、通话、紧急联系等适老证据，因此不强行给任何手机发“长辈适用”标签。
- 详情展示分类原因、机型级作用域、原始测试协议与条件、来源链接和规则版本。
