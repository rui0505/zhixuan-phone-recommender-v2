# 知选交互式算法实验报告（v0.2）

日期：2026-10-22

算法版本：`interactive-fusion-0.2.0-experimental`
性质：固定真实商品目录上的合成偏好实验；未进行真实用户效果验证。

## 1. 结论与证据边界

本轮证据支持在本目录、模拟偏好分布和五题预算下，信息增益追问能够改善部分排序指标；收益取决于回答后使用的排序规则。学习后的 VIKOR-Q 对照在三组数据、两类效用下均具有较高的取舍对准确率和 NDCG@5，学习后的加性效用也有明显收益。不能把这些结果外推为真实消费者效果或任何目录下的算法优越性。

RRF 融合没有表现出全面优势。它相对固定 TOPSIS 能提高成对排序准确率，但融合的 Top-1 后悔值在本轮所有模拟情景中均未随追问改善；同一回答轨迹上的学习后 VIKOR 明显优于融合。经典 TODIM 的权重行为还能抵消学习所得偏好，因此融合保留为实验对照，不应依据算法复杂度或“多算法”名称认定更优。

信息增益加分歧相对纯信息增益没有跨组稳定优势。负结果、区间跨零的比较，以及分歧策略偶尔更差的情况均保留。两组新增随机种子采用相同参数，没有从旧敏感性实验中选取最优参数作为本报告设置。

### 2.3 偏好生成、学习与问题选择

真实模拟权重从四维 `Dirichlet(1,1,1,1)` 抽取。设收益向量为 x、权重为 w：

- 线性效用：u(x)=Σ wⱼxⱼ。
- 短板敏感效用：u(x)=0.7Σ wⱼ√xⱼ+0.3 min(xⱼ)，最小值仅取权重不低于其中位数、且在目录中有变化的指标。该效用用于检查加性学习模型失配。

所有模拟用户均使用固定初始滑块 5:2:2:1，而真实权重按上述分布独立生成。因而本轮收益是在初始先验可能与个人真实偏好不匹配的设定下测得的，其中一部分可能来自纠正固定先验。实验没有模拟“自然语言需求已准确给出个人偏好”的初始化过程，不能宣称这种情况下仍有相同幅度的追问收益。

模拟回答采用 P(A)=0.05+0.9 sigmoid((u(A)−u(B))/0.10)。学习器采用加性回答模型，温度 0.12、噪声参数 0.10；两者不是完全相同的温度设定，也不代表测得的心理参数。

学习器为 128 个 Dirichlet 粒子，参数 αⱼ=1+12w₀ⱼ；初始粒子概率均匀。每个用户的真实偏好、学习器、留出划分和答案噪声使用分离的随机流；不同策略共享该用户的学习粒子。同一用户对同一候选对的噪声回答保持一致。回答后通过贝叶斯似然更新粒子概率。

每种追问策略最多五题。本轮各学习策略实际均完成五题。问题来自当前 TOPSIS、TODIM 和融合排名中各前八个独立机型代表的并集，排除相同机型、相同指标向量、Pareto 支配对、已询问对与留出测试对。不同策略执行同一候选池构建规则；回答使后验不同后，后续池可以随之不同，不声称整个过程中的候选池始终逐对一致。

三种选题策略为随机、信息增益 IG，以及 IG×(1+0.5D)。D 为两个排序专家对某对候选严格反序的后验概率；纯分歧而没有信息的问题不会单独得到奖励。默认经典 TODIM θ=1，RRF 的 TOPSIS 比例 α=0.5、平滑参数 k=10。

### 2.4 25 种方法与归因控制

每个情景包含五种固定参考权重排序、五种无回答粒子先验排序，以及三种追问策略各五种学习后排序：TOPSIS、经典 TODIM、VIKOR-Q 对照、加性效用、RRF 融合，共 5+5+3×5=25 种。

同一追问策略的五种学习后输出共用完全相同的问题、回答、粒子和后验，只改变最终排序规则。这能区分“回答学习的收益”和“换排序器的收益”。选题机制仍由三路排序共同构建，并非分别为 VIKOR 或加性效用优化的问题策略。

`fixed_*` 使用初始参考权重；`prior_*` 使用未回答时的粒子分布。先验平滑和排序期望本身就可能改变结果，所以学习收益应对比各自 `prior_*`，不能只对比 `fixed_*`。例如 `learn_information` 表示信息增益追问后的融合，`learn_information_vikor` 表示同一回答轨迹的 VIKOR 输出。

VIKOR 仅比较 Q 指数；排序采用 1−Q，Q 越小越好。未实现完整折中解接受条件，不能称为完整 VIKOR 折中解证明。Q 只作证据导出，不作为“越大越好”的另一条评测基线。

## 3. 指标与统计方法

每个用户对不同机型且指标向量不同的候选对随机留出 30%；本目录每个情景为 75 对。选题全过程排除这些留出对。对三份 JSON 的全部回答记录逐对检查，已询问对与留出对交集均为 0。原始组、复核 A、复核 B 分别包含 3600、14400、14400 个“情景×测试对”记录，但这些不是彼此独立的统计样本。

| 指标 | 定义与方向 |
|---|---|
| 全对准确率 | 留出对中预测方向与潜在效用一致的比例；预测同分计 0.5，真实效用同分不计。越高越好。 |
| 取舍对准确率 | 在留出对中进一步排除 Pareto 支配关系，只评价两者各有优劣的对。越高越好。 |
| Top-1 后悔值 | (最高真实效用−预测首位集合的平均真实效用)/(最高−最低真实效用)；并列首位均分。越低越好。 |
| NDCG@5 | 按潜在效用计算收益 2ᵘ−1；预测同分组取该组平均收益，避免 SKU 次序获利。越高越好。 |

取舍测试对数量分别为 2432、9986、9824；每个情景约 42–60 对。支配关系在所有正权重下都可能容易判断，因此同时报告全对与取舍对指标，不把全对准确率直接解释为个性化能力。汇总先对每个用户计算指标，再对用户取均值，不按候选对数量加权。Top-1 与 NDCG 是对全部冻结候选的推荐决策评价，不是仅在留出 SKU 上的冷启动测试；仅成对预测指标使用留出对。

配对区间直接取自 JSON 的 `paired_comparisons`：以同组、同效用族的用户为抽样单位，对“方法−参照”的逐用户差值进行 2000 次 bootstrap，取 2.5%/97.5% 分位数。区间条件于本目录和模拟机制，未做多重比较校正。正差值表示指标变大；后悔值的负差值才代表改善。区间跨零不支持稳定方向，区间不跨零也不等于现实人群效果已获确认。

## 7. 经典 TODIM 的反转行为与负结果

当前经典 TODIM 对收益差 δ 使用正差贡献 √(wδ)，负差贡献 −√(−δ/w)/θ。降低一个指标的正权重时，该指标的损失系数反而增大。因此它不具备“权重越小，对该指标越不在意”的简单加性语义；用加性回答模型学到的权重直接送入 TODIM，可能产生方向冲突。

可复现例：A 价格 1000 元、重量 200 克；B 价格 2000 元、重量 100 克。二者 min-max 收益向量为 A=(1,0)、B=(0,1)。价格/重量权重为 (0.8,0.2)，θ=1：

| 方法 | A | B | 解释 |
|---|---:|---:|---|
| TOPSIS | 0.8 | 0.2 | 偏向价格更低的 A |
| TODIM 原始占优总量 | −1.341641 | −0.670820 | A 在低权重重量维度的损失被放大 |
| TODIM 归一化 | 0 | 1 | 反而偏向 B |
| RRF，α=0.5、k=10 | 0.0871212 | 0.0871212 | 两路反序相互抵消，结果并列 |

对任意两个完全交叉指标，此例的 TODIM 占优差可写为
(√w₁−√w₂)×(1−1/(θ√(w₁w₂)))。
θ=1 且 w₁>w₂ 时，该差为负；这不是浮点舍入或标签顺序造成的现象。该例在偏好 A 后可出现“价格后验权重上升，但融合仍并列”。不能把粒子权重变化直接当作推荐改善。

三组记录中的学习后 TODIM 也保留了不利变化：

| 组别 | 效用族 | 取舍准确率：先验→信息追问后 | 后悔值：先验→信息追问后 | NDCG：先验→信息追问后 |
|---|---|---|---|---|
| 原始组 | 线性 | 0.7211→0.6958 | 0.2396→0.3030 | 0.8487→0.8337 |
| 原始组 | 短板敏感 | 0.6997→0.6767 | 0.3625→0.4223 | 0.7893→0.7698 |
| 复核 A | 线性 | 0.7300→0.7081 | 0.1986→0.2735 | 0.8718→0.8552 |
| 复核 A | 短板敏感 | 0.7114→0.6857 | 0.3023→0.3642 | 0.8245→0.8043 |
| 复核 B | 线性 | 0.7423→0.7203 | 0.1533→0.2273 | 0.8921→0.8767 |
| 复核 B | 短板敏感 | 0.7015→0.6715 | 0.2805→0.3724 | 0.8384→0.8145 |

这些 TODIM 变化为描述性均值，本报告不为未预置的比较额外声称显著性。它们说明回答模型与排序模型的接口语义需要检验。经典 TODIM 可以保留为透明对照；若未来引入具有不同权重语义的变体，必须单独命名、说明公式差异并重新验证，不能沿用经典算法名称掩盖修改。

## 10. 下一步：真人对照研究

在进入真实用户研究前，先固定主要结局、算法参数与分析计划，扩大品牌、价位、配置和指标覆盖，并验证缺失指标与评测口径。由参与者确认真实预算、使用场景及限制，明确数据与隐私用途。

建议分别检验“同一排序器下追问有无收益”和“同一回答后不同排序器的推荐差异”。采用随机分组或次序平衡的交叉设计，控制提问数量与耗时；保留未询问的独立偏好判断，比较真实选择一致性、决策信心、满意度及完成时间。题序和输出展示应避免算法名称暗示，分析应按参与者配对或聚类，并事先确定多重比较处理。

样本量依据预先指定的最小有意义效果和先导研究估计确定，不以本次模拟区间直接推导“足够人数”。调参与最终测试使用不同参与者；若按人群细分，预先说明分层。最终仍需报告负结果、退出和无明显偏好情况。只有完成这些研究后，才评估真实推荐收益及是否适合修改生产默认策略。
