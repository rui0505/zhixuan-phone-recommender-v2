# 手机选购体验改进：提交审核说明

本次提交到功能分支，供团队审核；不是合并或公网部署记录。

## 本次功能

- 推荐卡片以普通选购语言展示匹配点、取舍和数据限制；计算分数、版本、权重和事实 ID 保留在折叠的技术依据内。
- 手机库新增游戏、长辈友好、拍照三个入口，支持查看已有参考证据或待评估机型，并展示规则与来源。
- 一并提交当前网页运行所需的需求抽取接口、前端交互、玻璃样式和已选科技主视觉，避免遗漏本地未跟踪的依赖。默认不新增付费模型调用。

## 分类含义与边界

分类是参考证据状态，不是质量认证，也不改变原始参数和推荐排名。

当前发布库共 147 个机型：游戏有参考证据 65 个、待评估 82 个；拍照有参考证据 55 个、待评估 92 个；长辈友好全部 147 个待评估。实际页面数量还会受价格、存储、品牌及成色等条件影响。

游戏仅接受模型级、作用域匹配且有来源的正数游戏帧率；拍照仅接受指定拍照分项，不用像素数或综合分冒充拍照能力。长辈友好尚缺大字体、简易模式、紧急求助等专项证据，不能因为电池大或价格低就贴标签。社区讨论仅帮助制定规则，不构成逐机型实测。

自然语言理由由已校验的同一份决策结果确定性生成，不让大模型虚构卖点。同条件价格比较需要明确且一致的完整日期与条件；未知或模糊日期不得当作同日现价。型号级评测不能宣称为每个配置的独立实测。
